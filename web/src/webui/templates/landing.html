How It Works

Three steps to total coverage

LangGraph orchestrates an optimization loop powered by Gemini that iterates until your coverage threshold is reached.

01
Upload C++ Source

Drop your .cpp file or write code directly in the browser. Configure coverage type (line/branch/function) and thresholds.

02
AI Generates Tests

Gemini Pro analyzes uncovered statements, generates targeted test inputs, and the tool compiles and runs them — all automatically.

03
Coverage Maximized

The loop iterates up to N times, with mutation testing triggered at 100% line coverage to validate test quality and kill mutants.

Features

Everything you need to test smarter

LLM-Driven Test Generation

Gemini Pro identifies uncovered code paths and generates precise test inputs to execute them — no manual effort required.

Mutation Testing Layer

When line coverage hits 100%, the tool introduces code mutations to verify that your test suite actually detects defects.

Three Coverage Modes

Choose between statement, branch, or function coverage with configurable thresholds. Mix objectives with Hybrid mode.

LangGraph Orchestration

The optimization loop is modeled as a typed state graph — compile → run → parse → LLM → iterate — with full traceability.

Real-time Progress

Watch coverage climb in real-time. The web UI polls for status updates and redirects to a rich results dashboard on completion.

Validation & Rejection Reasons

Every generated test is validated before acceptance. Rejected tests include structured reasons, enabling iterative refinement.
